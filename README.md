# Houmi · Колекція «Берегиня» — сайт-каталог

Односторінковий сайт українською, польською та англійською. Українська мова відкривається за замовчуванням.

## Що всередині

```
houmi-berehynia/
├── index.html          ← увесь сайт: тексти, стилі, код
└── assets/
    ├── logo/           ← логотип, фавікон
    ├── products/       ← фото свічок (оригінал + зменшена копія -640)
    ├── brand/          ← фірмова спіраль
    └── fonts/          ← шрифт Inter (ліцензія OFL)
```

## Як відкрити

Розпакуйте архів і двічі клацніть `index.html`. Сайт відкриється в будь-якому браузері без інтернету.

## Звідки тексти

Усі описи перенесено дослівно з другої сторінки оригінальних карток (PDF, UA / PL / EN).

## Як змінити текст або додати нову свічку

Усі дані лежать на початку блоку `<script>` в `index.html`, у розділі **«ДАНІ КАТАЛОГУ»**. Відкрийте файл у будь-якому текстовому редакторі (TextEdit у режимі «простий текст», Notepad або VS Code).

Для кожної свічки там є:

- `name` — назва трьома мовами;
- `symbols` — рядок символів із картки, він показується в каталозі під назвою;
- `text` — повний опис, кожен рядок у `[ ]` — окремий абзац;
- `wishLabel` і `wish` — «Її побажання» та сам текст побажання;
- `alt` — опис фото для незрячих відвідувачів і пошукових систем.

Щоб додати нову свічку, скопіюйте блок `{ … }` однієї зі свічок, змініть `id`, тексти й шляхи до файлів і покладіть фото в `assets/products/`. Фото краще готувати в пропорції 4:5 зі свічкою по центру, як у наявних.

Коли вступ до колекції буде погоджено, змініть `INTRO_APPROVED = false` на `true`, і коричнева смуга «Чернетка» зверху зникне.

## Корисні посилання на конкретну свічку

Додайте до адреси сайту `#назва`, щоб одразу відкрити потрібну свічку. Мову задає `?lang=`:

- `…/#home`, `…/#christmas`, `…/#abundance`, `…/#love`, `…/#family`, `…/#wealth`;
- `…/?lang=pl#love` — польською, `…/?lang=en#wealth` — англійською.

Це зручно для сторіз в Instagram і повідомлень клієнтам на Etsy.

## Як опублікувати (безкоштовно)

### Варіант 1 — Netlify Drop (найпростіше, ~3 хвилини)

1. Зайдіть на https://app.netlify.com/drop і зареєструйтеся (можна через Google).
2. Перетягніть **папку** `houmi-berehynia` (саму папку, не zip) у вікно браузера.
3. Ви отримаєте адресу на кшталт `random-name.netlify.app`.
4. Змініть назву: Site configuration → Change site name → `houmi-berehynia`. Нова адреса: `houmi-berehynia.netlify.app`.
5. Щоб оновити сайт: Deploys → перетягніть папку ще раз.

### Варіант 2 — GitHub Pages

1. Створіть акаунт на github.com і новий публічний репозиторій, наприклад `berehynia`.
2. Add file → Upload files → перетягніть **вміст** папки (`index.html` і `assets`) → Commit.
3. Settings → Pages → Branch: `main`, folder `/root` → Save.
4. Через 1–2 хвилини сайт буде доступний за адресою `https://<ваш-нік>.github.io/berehynia/`.
